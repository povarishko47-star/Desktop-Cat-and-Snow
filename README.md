# ❄️🐈 Desktop Snow & Black Ragdoll Cat

Two lightweight desktop overlay apps for Windows that work both standalone and together:

* **`DesktopSnow.exe`** — realistic 60 FPS desktop snow simulator. Snowflakes react to mouse movement (creating vortices), accumulate into snowdrifts on the taskbar and top edges of open windows, and slide off naturally when windows are moved.
* **`BlackCat.exe`** — an interactive 60 FPS black ragdoll kitten. It walks along your taskbar and window borders, grooms itself, sleeps, occasionally says *"meow"*, and dangles with full ragdoll physics when picked up.

### ✨ Interactive Synergy
Run both apps at the same time to unlock their interaction: whenever a snowdrift builds up on the taskbar, the kitten will sprint toward it and leap right in, scattering snowflakes into the air.

### 📥 Where to Download & How to Run
1. Go to the **[Releases](../../releases)** section on the right sidebar of this repository (or click **Latest** under *Releases*).
2. Under **Assets**, download **`DesktopSnow.exe`** and **`BlackCat.exe`**.
3. Double-click either (or both) `.exe` files to launch — no installation or Python/runtime setup required.
4. **Windows SmartScreen Note:** Because these indie executables are unsigned, Windows may show a *"Windows protected your PC"* popup on the first launch. Click **More info** → **Run anyway**.

### 🎮 Controls
* **Black Cat (`BlackCat.exe`):**
  * **Left-Click & Drag:** Grab any part of the kitten to move it around, drop it onto the top edge of any open window, or toss it into a snowdrift.
  * **System Tray Icon (Right-Click):** Reset the kitten back to the taskbar or exit the app.
* **Desktop Snow (`DesktopSnow.exe`):**
  * **Move Mouse:** Create wind vortices and scatter snowdrifts.
  * **`Ctrl + Alt + S`:** Instantly clear all snow.
  * **System Tray Icon (Right-Click):** Clear snow, toggle *Run on Windows Startup*, or exit.
